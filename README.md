A mobile fitness product designed to help beginner and intermediate athletes log workouts, follow routines, monitor progress, and improve their exercise technique through future AI-assisted feedback.

The project includes user research, personas, information architecture, user flows, wireframes, a UI system, a high-fidelity interactive prototype, and usability testing. Testing findings were used to improve the application's navigation and overall experience.

**Focus:** Mobile Product · Fitness Technology · UX Research · UI Design · Usability Testing · AI-Assisted Training
